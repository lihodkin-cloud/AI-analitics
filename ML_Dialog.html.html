Маршрутні листи

PDF створюється з оригінального аркуша «Шаблон МЛ». Рамки, шрифти, висота рядків, ширина стовпців і відривна бирка зберігаються як у Google Sheets. Готовий PDF відкривається у новій вкладці Chrome для перегляду й друку. Один МЛ з биркою — одна сторінка А4.

Створюється номер Д-12-345, Д2-12-345 тощо. Кількість щитів, що залишилися, майстер вписує вручну.

Кожний комплект містить два МЛ: один для преса .1, другий — для .2. Наприклад, 4 комплекти = 8 МЛ.

Увага: номер закріплюється в «Журналі МЛ» перед початком експорту. Після скасування друку номер не використовується повторно. Створення великої кількості сторінок може тривати кілька хвилин.
